# Screenshot Source Notes

The v0.3 demo project is intended to be the source data for future screenshots
and the public read-only demo site.

Current filled-state screenshots in `docs/screenshots/` were captured from
representative demo data. Future screenshot refreshes should prefer this
directory's manifest and texts so docs, tests, and visual assets stay aligned.

Suggested mapping:

- Text comparison: `texts/base-punctuated.txt` + `texts/witness-variant.txt`
- Punctuation transfer: `texts/base-punctuated.txt` + `texts/target-unpunctuated.txt`
- Overview workspace: any project seeded from `manifest.json`
