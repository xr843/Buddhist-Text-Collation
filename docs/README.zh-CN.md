**Platform for Buddhist Text Punctuation and Collation Research**

佛经古籍标点比较与校勘研究平台。提供标点版本对比、两版本对勘、多版本对勘、版本谱系分析、经论注疏对读等功能，帮助研究者高效完成佛典文献的校勘工作。

> **关于本文档**：这是历史完整版中文文档（V1 → V2.10 演进记录），作为**研究背景与设计思路参考**保留。它可能包含已下线、已重做、需要自配第三方凭据，或仅在早期内部版本存在的功能说明。请以仓库根目录的 [`README.md`](../README.md)、[`ROADMAP.md`](../ROADMAP.md) 与 [`CHANGELOG.md`](../CHANGELOG.md) 为当前功能、版本和部署边界的权威说明。

## 核心功能

### 🧘 禅意/学术 UI（P0）

面向“长时间阅读/对照/判取”的真实研究工作流，提供更护眼、更沉浸的界面体验：

- **沉稳护眼配色**：主色靛青（#384E77）+ 强调朱砂（#C64153）+ 米白底色（#FDFBF7）
- **典雅排版**：标题使用衬线体（Noto Serif SC / 思源宋体回退），古籍阅读区域（`.ancient-text`）默认更大字号与更舒适行高
- **差异高亮更清晰**：插入/删除/替换/异体字采用柔和但可辨识的配色体系
- **专注模式（Zen Mode）**：一键隐藏侧边栏/顶栏，仅保留内容区与浮动工具条（用于长时间校勘）
- **入口**：页面右上角“专注模式”按钮进入/退出


### 标点版本对比（重点功能）
- **精准差异定位**：逐字对比两个版本的标点差异
- **三类差异分类**：
  - 句末点号（。？！）— 影响句子边界
  - 句内点号（，、；：）— 节奏停顿
  - 标号（引号、括号、书名号等）
- **双向位置索引**：精确定位每个差异在两个版本中的位置
- **差异统计**：总差异数、分类统计、审核进度跟踪
- **CSV报告导出**：导出包含逐条差异明细的详细报告
- **智能块对齐**：N句对M句的灵活对齐算法
- **行号显示**：便于定位和引用
- **每行字数控制**：灵活调整显示密度
- **两版本文字对齐**：并排对照，差异一目了然
- **🆕 标点定本生成**：逐条审定标点差异后，一键生成标点定本
- **🆕 标点改易记**：自动生成标点改动记录，记录每处改动的位置、原标点、改后标点

### 🆕 标点迁移（V2.8新增）

**将已标点文本的标点符号迁移至另一份无标点的相似文本中**，适用于利用已有标点版本快速生成新版本标点。

**核心功能**
- **智能对齐**：使用编辑距离（Levenshtein）算法对齐两个纯文本
- **位置映射**：根据对齐结果，将源文本的标点位置映射到目标文本
- **智能验证**：避免在词语中间插入标点，内置佛典常见不可分割词语库
- **相似度检测**：自动计算两个文本的相似度，相似度过低时给出警告

**操作流程**
1. **输入来源文本**：粘贴或上传已标点的文本（如CBETA版本）
2. **输入目标文本**：粘贴或上传无标点的文本（如自有 OCR 识别结果）
3. **一键迁移**：点击"进行迁移"按钮，自动完成标点迁移
4. **导出结果**：复制到剪贴板或导出为txt文件

**特色功能**
- **清除标点**：一键清除目标文本中已有的标点符号
- **加载示例**：提供佛典示例文本，快速体验功能
- **文件上传**：支持上传txt文件作为来源或目标文本
- **字数限制**：单次处理上限5万字，满足大部分经卷需求
- **保留换行**：迁移后保留原始文本的换行格式

**应用场景**
- 📚 **外部 OCR 后处理**：将其他工具识别的无标点文本快速加上标点
- 📖 **版本迁移**：将CBETA标点迁移到其他版本文本
- ✍️ **校对辅助**：基于已标点版本快速生成待校对文本

### 两版本对勘（文字校勘）
- **差异识别**：识别差异类型（异体字、讹误、衍文、脱文、倒文）
- **异体字过滤**：集成24,255字异体字库，自动过滤异体字差异
- **序号显示**：自动生成差异序号，方便引用
- **校勘记编辑**：支持富文本校勘记撰写

### 多版本对勘（V2.3增强）
- **大规模版本对勘**：支持 **1底本 + 30校本 = 31个版本** 同时对勘
- **藏经版本覆盖**：满足大正藏、丽藏、频伽藏、房山石经等多藏经对勘需求
- **异文汇校表**：
  - 固定列设计：序号、上下文、底本（左固定）+ 类型、操作（右固定）
  - 中间校本列可横向滚动，支持30+列显示
  - 版本名简称显示，悬停查看全名
- **批量上传**：支持一次性多选30个校本文件，标签式紧凑展示
- **智能导出**：汇总统计、异文汇校表、全量对照表、综合报告多种导出格式
- **🆕 全量对照表**（V2.10新增）：导出包含所有字符位置的完整对照表
  - 逐字对照：底本每个字符与各校本对应字符并列
  - 上下文定位：显示前后3字上下文，方便定位
  - 异文标记：标注相同/异文/脱文等类型
  - 统计信息：相同字数、异文字数、总字数汇总
- **项目制工作流**：项目化管理校勘任务
- **学术报告**：一键生成符合规范的校勘报告

### 🆕 四校法校勘判取（V2.5新增）

**基于陈垣"四校法"的专业校勘判取系统**，为每条异文提供规范化的判取依据。

**四校法框架**
- **对校**：依据版本对比
  - 多数版本一致、版本年代较早、版本权威性高
  - 版本系统可靠（中系/南系/北系）、梵/藏本可参
- **本校**：依据本经内证
  - 同经前后文一致、符合本经体例、与同经其他章节呼应
  - 科判结构一致、法相术语一致
- **他校**：依据他经旁证
  - 他经引用一致、注疏引文一致、相关典籍佐证、同本异译一致
- **理校**：依据义理推断
  - 义理更通顺、形近而讹、音近而讹
  - 符合佛教术语习惯、符合语法规则
  - 符合法相定义、符合宗义立场、梵文还原合理

**判取功能**
- **逐条判取**：对每条异文选择采用的版本和文字
- **多重依据**：可同时勾选多种四校法依据
- **详细说明**：支持撰写判取理由和校勘说明
- **存疑标记**：对难以确定的异文可标记为"存疑"
- **🆕 定本生成**：完成判取后一键生成校勘定本
- **🆕 校勘记导出**：自动生成包含四校法依据的校勘记

### 🆕 版本谱系分析（V2.3新增）

**专业级版本学研究工具**，基于现代文献学方法论，为大藏经版本研究提供数据支持。

**完整相似度矩阵**
- **真实相似度计算**：所有版本两两对比，基于文本直接计算
- **动态热力图可视化**：支持31个版本的完整矩阵展示
- **智能版本名简化**：自动识别藏经核心名称，支持10-31个版本的自适应显示
- **数值表格对照**：提供精确相似度数值，便于学术引用

**共同异文分析**
- **三类异文识别**：
  - 共同讹误（同位置、同内容的抄写/刻印错误）
  - 共同异体字（同位置、同字形的异体字选择）
  - 共同衍脱（同位置的衍文/脱文）
- **亲缘关系判断**：共同异文是版本谱系学中判断版本亲缘关系的重要证据
- **热力图展示**：可视化显示版本间共同异文数量
- **详情追溯**：点击单元格查看具体异文位置和内容
- **统计汇总**：各版本异文总数统计，按数量降序排列

**版本系统归属（团队标准）**
- **汉文大藏经三系分类**：
  - 中系（开宝藏系）：高丽藏、赵城金藏、大正藏、中华藏等
  - 南系（福建/江浙系）：崇宁藏、思溪藏、碛砂藏、嘉兴藏等
  - 北系（契丹系）：契丹藏、房山石经等
- **自动识别**：基于版本名称关键词自动归类
- **色彩标注**：不同系统用不同颜色标识，一目了然

**UPGMA 谱系树**
- **层次聚类算法**：使用非加权组平均法（UPGMA）生成
- **树状结构可视化**：清晰展示版本间的亲疏关系
- **相似度标注**：每个节点显示与底本的相似度百分比
- **系统归属标签**：自动标注版本所属系统

**分析结论自动生成**
- 最相似版本对识别
- 按系统分组统计
- 共同讹误最多的版本对
- 为学术研究提供数据支撑

**🆕 版本源流图（V2.9新增）**

基于版本谱系数据推断版本传承关系，生成有向无环图(DAG)可视化。

- **传承关系推断**：基于时间约束、共同讹误、系统归属等多因素推断"谁抄自谁"
- **推断规则**：
  - 时间约束：年代晚的版本不能是年代早的版本的源头
  - 共同讹误证据：共同讹误越多，传承关系越近
  - 系统一致性：同系版本优先考虑传承关系
  - 祖本优先：开宝藏(中系)、契丹藏(北系)、崇宁藏(南系)作为各系起点
- **置信度计算**：综合相似度(30%)、共同讹误(40%)、系统一致(20%)、祖本关系(10%)
- **可视化编码**：
  - 节点颜色：按系统着色（中系黄/南系绿/北系蓝/近现代紫/未知灰）
  - 节点大小：祖本较大
  - 边粗细：按传承置信度
  - 边样式：实线=高置信度(≥70%)，虚线=推测关系
- **三格布局**：左侧图谱 + 右上分析结论 + 右下传承关系列表
- **交互功能**：悬停查看详情、点击高亮关联、拖拽调整布局
- **传承关系表**：按置信度排序，显示源版本、目标版本、证据

**版本谱系报告导出（V2.8新增）**
- **一键导出CSV报告**：在导出菜单中选择"版本谱系报告"
- **报告内容完整**：
  - 版本谱系分析结论（最相似版本对、南系/北系分析等）
  - 版本系统分类（中系/南系/北系归属 + 系统汇总）
  - 相似度矩阵表格（完整N×N矩阵 + 相似度排名前10对）
  - 共同异文统计（讹误/异体字/衍脱三种类型的矩阵、各版本总数、详情明细）
- **Excel兼容**：UTF-8 BOM编码，可直接用Excel打开

**地理分布可视化（V2.4新增）**
- **版本地理地图**：在中国地图上显示各藏经刻印地
- **40+藏经坐标**：涵盖高丽藏、赵城金藏、房山石经等主要版本
- **相似度标注**：圆点大小和颜色表示与底本的相似度
- **地理聚类分析**：统计各省份版本数量和平均相似度
- **底本标记**：红色图钉突出显示底本位置
- **交互式操作**：支持缩放、平移，悬停查看详细信息

### 🆕 经论注疏对读（V2.7新增）

**三栏对读界面**，支持经论与多部注疏的并行阅读，基于DILA科判数据实现精确对齐。

**核心功能**
- **三栏布局**：经论（底本）+ 两部注疏，独立滚动
- **精确对齐**：基于DILA瑜伽师地论数据库的科判对应关系
- **对齐跳转**：点击底本段落，注疏自动滚动到对应位置
- **对应标记**：底本段落显示"有注疏"标签，一眼识别可点击的段落
- **阅读设置**：字体大小、行高、护眼色（5种背景色）
- **关键词搜索**：实时高亮搜索结果

**支持典籍**
- 📖 《瑜伽师地论》100卷（底本）
- 📝 《瑜伽论记》48卷（遁伦集撰，DILA已完成24卷科判）
- 📝 《瑜伽师地论略纂》16卷（窥基撰）

**性能优化**
- **预处理JSON**：DILA HTML一次性解析为JSON，启动时加载到内存
- **毫秒级响应**：告别每次请求都解析HTML的延迟

**数据来源**
- [DILA 瑜伽师地论数据库](https://ybh.dila.edu.tw) — 法鼓文理学院数位典藏组

**应用场景**
- 📚 **注疏研究**：快速定位注疏中引用的原典
- 🔍 **校勘辅助**：通过原典验证注疏文本的准确性
- 📊 **引用分析**：分析一部注疏引用了哪些经典

## 使用说明

## 常见问题

### 后端启动失败：端口8000被占用

```bash
# 查找占用端口的进程
lsof -ti:8000

# 杀死进程
kill -9 $(lsof -ti:8000)
```

### 访问 `http://localhost:8000/docs` 显示 404

后端默认仅在 `DEBUG=true` 时开启 `/docs` 和 `/redoc`：
- 本地开发：在 `backend/.env` 里设置 `DEBUG=true`
- Docker：将 `docker-compose.yml` 里 `backend.environment.ENV` 改为 `development`，并设置 `backend.environment.DEBUG` 为 `"true"` 后重启

## 更新日志

### 2026-02-04
- ✨ 新增：全量对照表导出功能（V2.10核心功能）
  - 导出包含所有字符位置的完整对照表（无论是否有异文）
  - 格式：序号 | 上下文 | 底本 | 校本1 | 校本2 | ... | 类型
  - 上下文显示：前3字【当前字】后3字，方便定位
  - 基于规范化文本对齐，确保底本与校本位置精确匹配
  - 自动标注：相同/异文/脱文等类型
  - 统计信息：相同字数、异文字数、总字数
- 🐛 修复：全量对照表中底本空白问题（原因：原始文本与规范化文本位置不一致）
- 📝 文档：更新README至V2.10

### 2026-01-25
- ✨ 新增：版本源流图功能（V2.9核心功能）
  - 基于版本谱系数据推断版本传承关系，生成有向无环图(DAG)
  - 多因素推断算法：时间约束、共同讹误、系统归属、祖本关系
  - 置信度计算：相似度(30%) + 共同讹误(40%) + 系统一致(20%) + 祖本(10%)
  - 视觉编码：节点按系统着色（中系黄/南系绿/北系蓝）、边按置信度粗细和虚实
  - 三格布局优化：左侧图谱 + 右上分析结论 + 右下传承关系列表
  - 交互功能：悬停查看详情、点击高亮关联边、拖拽调整布局
- 🔧 新增：`backend/app/services/lineage_service.py` 版本源流推断服务
- 🔧 新增：`frontend/src/components/phylogeny/LineageGraph.tsx` 源流图组件
- 📝 文档：更新README至V2.9，新增版本源流功能介绍
