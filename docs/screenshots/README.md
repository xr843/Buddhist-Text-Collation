# 截图目录 / Screenshots

为 README 与文档提供可视化材料。建议尺寸：

- 主界面 / overview：1600 × 1000，PNG
- 子模块 / module：1280 × 800，PNG（带说明文字）
- GIF 演示：< 5MB，10-15 秒

文件命名：
- `overview-main.png`
- `feature-multi-collation.png`
- `feature-punctuation-diff.png`
- `feature-commentary-parallel.png`
- `feature-lineage-graph.png`
- `social-preview.png`（GitHub Social Preview，1280 × 640）

提交截图前请确认：
- 不含真实用户名 / 个人信息
- 不含本地路径
- 不含未公开发布的文本数据

## GitHub Social Preview

- Canonical source: `docs/assets/social-preview.svg`
- GitHub-ready export: `docs/screenshots/social-preview.png` (1280 × 640)
- Upload path: repository **Settings → Social preview → Edit**.

The preview is original vector artwork built from project themes only: Buddhist text collation, source comparison, punctuation diff, commentary reading, and public scholarly resources. It avoids external imagery so the asset can be reused safely in repository documentation and GitHub link previews.
